# ROOM9 Windows — consolidated replacement (Nov 11 2026)

**Only current archive:** [ROOM9_WINDOWS_ALL_IN_ONE_COMPLETE.zip on Google Drive](https://drive.google.com/file/d/1lePBOGcrsy0NRAAEmxFnFm-eOAbC198g/view)

- File size: **24,831,330 bytes**, 27 archived files.
- SHA-256: `c95b47ad1e35267fbc271b73975f4d347efa2d84d36c19d923c920b688f7fa48`.
- Open `ROOM9_WINDOWS_ALL_IN_ONE/START_ROOM9.cmd` after extracting the ZIP.
- **Windows PowerShell 5.1 x64** built-in `Add-Type` compiles the bundled C# bridge at startup; no manual MSVC build needed.
- The ZIP contains genuine Windows PE DuckDB ODBC C ABI and ONNX Runtime DLLs, four ONNX models, seven JSON/Parquet datasets, archived Lance fragments and original ROOM9 reference interface.
- Runs a new localhost native DuckDB read-only SQL/JSON console. Original `C:\WEB CASE STUDY\web_intel_sonicdb.duckdb` is opened read-only if present.
- Available workstation custom native DLLs beginning with sovereign, legion, room9, lance are discovered and loaded only if Windows PE. Loading alone does not establish actor SQL bindings.
- The package **has not been executed on Windows**, so do not present the entire historical actor graph, native Lance ANN, or ONNX SQL inference as verified. It is a complete archive for the bounded Windows ROOM9 console, not the complete historical Sovereign DAW ecosystem.

The older separate Linux native ZIP and Windows build ZIP were superseded and intentionally removed from Library and Google Drive at the user's request. The ZIP itself is stored on Drive, **not** checked into GitHub. GitHub holds the distribution manifest.
